# 오호플 공간 규칙 (요약)

원문 문서: https://claude.ai/artifact/9CNfzjk8DmEUcrSQxCLgrz

- 분류(type) 5가지: PLAY 놀이 · USE 도구 · CREATE 만들기 · LEARN 배우기 · EXPLORE 탐험. 애매하면 첫 1분 동안 하는 일로 하나만.
- 장소(zone)는 분류의 집:
  - 놀이(PLAY) → zone:'놀이 섬' (서쪽 골목 끝 무지개 다리, 회전목마 섬. 안쪽 12칸 + 가운데 11칸 + 바깥 산책로 너머 12칸 = 35칸)
  - 도구(USE) + 일에 쓰는 만들기·배우기 → TOOL_WORKS, zone:'도구 섬'
  - 만들기·배우기 → zone:'골목', side:'west'
  - 탐험 → zone:'골목', side:'east'
  - 교회·성당·절 → FAITH_WORKS (성소 언덕)
- 승격 자리: 큰길(zone:'큰길', 반응이 쌓인 작품, moved:true), 분수 광장(매주 반응 상위 4개 featured).
- 새 작품: 원본이 실제로 열리고 휴대폰에서 되는지 확인 → 분류 → 그 집의 빈 가게(…_VACANTS 개수 줄이기) → 썸네일·작품 페이지.
- 집이 차면 다른 집에 끼워 넣지 않고 같은 분류 구역을 넓힌다(섬 고리 추가 → 두 번째 섬). 골목은 더 늘리지 않는다.
